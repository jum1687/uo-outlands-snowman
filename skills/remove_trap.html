概要 Summary

在 Outlands 中，Remove Trap（解除陷阱）的功能已合并入 Detecting Hidden（侦察隐藏）。玩家使用陷阱工具（Trap Tools）配合侦测隐藏来清除地下城 / 典范宝箱（Dungeon / Paragon Chests）上的陷阱。需要至少 80 点侦测隐藏才能操作，解除陷阱成功率 = (有效侦测隐藏 − 宝箱最低技能) × 2.5%。

说明：原版 UO 中的 Remove Trap 作为一个独立技能，在 UO Outlands 已并入侦察隐藏（Detecting Hidden）。相关机制以下引自侦察隐藏官方页的 "Removing Traps" 章节。

解除陷阱 Removing Traps

在 Outlands 中，解除陷阱技能的功能已合并入侦察隐藏。

地下城宝箱 Dungeon Chests

  • 地下城宝箱拥有从 1 到 8 级（依据地牢位置）的陷阱难度，以及 0–100% 的解除陷阱进度值
  • 玩家可使用陷阱工具对宝箱尝试解除陷阱，成功会提升陷阱进度
  • 若宝箱解除陷阱进度低于 100%，玩家在尝试开锁时有一定几率触发陷阱，从而取消其尝试
  • 玩家触发宝箱陷阱不会改变该宝箱的解除陷阱进度（即宝箱可触发多次陷阱）
  • 触发陷阱的玩家在接下来 5 秒内无法使用隐藏（Hiding）技能，也无法通过隐身术（Invisibility）隐藏
  • 陷阱的威力与效果随宝箱陷阱难度等级提升
  • 随着宝箱解除陷阱进度提高，开锁与解除陷阱时触发陷阱的几率都会下降
  • 玩家成功解除陷阱的几率 = ((有效侦测隐藏技能 − 宝箱最低技能) × 2.5%)
解除陷阱成功率 = (有效侦测隐藏技能 − 宝箱最低技能) × 2.5% 最低所需侦察隐藏 = 80

工具加成 Tool Bonus

材质 / 有效技能加成 / 进度加成：卓越（Exceptional）+10 / +25%；铁（Iron）+1 / +2.5%；钝铜（Dull Copper）+2 / +5%；影铁（Shadow Iron）+3 / +7.5%；铜（Copper）+4 / +10%；青铜（Bronze）+5 / +12.5%；金（Gold）+6 / +15%；银铅矿（Agapite）+7 / +17.5%；绿银矿（Verite）+8 / +20%；Valorite +9 / +22.5%；Avarite +10 / +25%

宝箱难度 Chest Difficulty

宝箱难度 / 等级 / 最低技能 / 进度几率：无价值（Worthless）1 / 0 / ((40% 到 80%) × (1 + 工具加成))%；极易（Very Easy）2 / 25 / ((36% 到 72%) × (1 + 工具加成))%；容易（Easy）3 / 50 / ((32% 到 64%) × (1 + 工具加成))%；普通（Average）4 / 75 / ((28% 到 56%) × (1 + 工具加成))%；困难（Difficult）5 / 95 / ((24% 到 48%) × (1 + 工具加成))%；极难（Very Difficult）6 / 105 / ((20% 到 40%) × (1 + 工具加成))%；极度困难（Extremely Difficult）7 / 115 / ((16% 到 32%) × (1 + 工具加成))%；几乎不可能（Nearly Impossible）8 / 125 / ((12% 到 24%) × (1 + 工具加成))%
