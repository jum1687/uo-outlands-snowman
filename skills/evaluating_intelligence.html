智力评估 Evaluating Intelligence

目录
  1. 概要 / Summary
  2. 打怪加成 / PvM Bonus
  3. 玩家对战加成 / PvP Bonus
  4. 训练 / Training

概要 Summary

智力评估（Evaluating Intelligence）技能被动提升魔法（Magery）法术对生物与玩家的伤害。

  • 智力评估用于提升魔法法术的伤害与效果
  • 施法时，潜在伤害会根据法术、其圈数、法术书或技能等多项因素计算，随后再根据法师的智力评估进行缩放
  • 智力评估可替代动物知识（Animal Lore）来查看生物的属性

打怪加成 PvM Bonus

对生物的基础法术伤害按（0.75 + (0.75 × (智力评估 / 100))）修正。100 点智力评估提供 50% 法术伤害提升，而 0 点智力评估提供 -25% 伤害提升。

PvM 法术伤害系数 = 0.75 + (0.75 × (Eval / 100)) Eval = 100 → 系数 1.50（即 +50% 法术伤害） Eval = 0 → 系数 0.75（即 -25% 伤害）

玩家对战加成 PvP Bonus

对玩家的基础法术伤害按（0.75 + (0.375 × (智力评估 / 100))）修正。

PvP 法术伤害系数 = 0.75 + (0.375 × (Eval / 100)) Eval = 100 → 系数 1.125（即 +12.5% 法术伤害）

辅助技能（追踪、露营、抄写等）存在 10% 的法术伤害上限。该上限不考量你的智力评估技能值，因此若你智力评估为 0，即便同时使用追踪与露营也无法获得 20% 法术伤害。但你可以拥有 100 智力评估与 100 追踪，从而获得 22.5% 的法术伤害提升。

总法术伤害系数（PvP）= (0.75 + 0.375 × (Eval / 100)) + 辅助技能加成（上限 10%） 示例：Eval 100 + Tracking 100 → 1.125 + 0.10 = 1.225（即 +22.5%）

训练 Training

  • 0–50 向 NPC 训练
  • 50–80 在新手地牢施放法术；对新手地牢中的目标使用该技能（不消耗资源，但耗时更长）
  • 80–100 施法时被动获得；对目标使用该技能（不消耗资源但耗时更长）
