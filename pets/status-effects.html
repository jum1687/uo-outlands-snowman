二、破甲 / 破魔抗机制 Armor Break

  • 护甲（Armor）与魔法抗性（Magic Resist）地板均为 0，不能为负。
  • 溢出不线性转伤，而是固定档：
    • 锤类特攻：基础 +100% 伤害 +25 Pierce；当目标护甲触底 / 为 0 时，再固定 +50%（合计最高 +150%）。
    • 「无视护甲 / 魔抗」类技能：对 0 甲目标固定 +15%（PvP 不生效）。
  • ⚠️ 宠物技能施加的 Pierce / Hex 无溢出 / 触底补偿——即宠物打 0 甲目标不会吃到上述 +50% / +15% 额外档位。
  • ⚠️ 旧版「溢出等值转伤」规则已废止。引用官方机制请以当前页 + 页脚修订日期为准。
