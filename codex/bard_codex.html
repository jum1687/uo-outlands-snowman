音乐宝典 Bard Codex

类型 音乐 Bard · 使用要求 音乐家(Musicianship) / 不和谐(Discordance) / 安抚(Peacemaking) / 挑衅(Provocation) 四项吟游技能中，至少两项达到 80

概述 Summary

  • 玩家可用抄写（Inscription）技能制作音乐宝典（Bard Codex）。
  • 音乐宝典为祝福（Blessed）状态，允许玩家自定义其吟游效果（Barding Effects）的处理方式。
  • 玩家需在至少两项吟游技能（音乐家、不和谐、安抚、挑衅）中达到 80 或以上，方可使用音乐宝典并从中获取经验。

Bard Codex 档案 Bard Codex Profile

  • 当持有音乐宝典且技能达标的玩家，对生物施加了吟游效果（不和谐、安抚、挑衅）时，将根据该玩家及其随从（Followers）对该生物造成的总伤害获得音乐宝典经验；经验再按生物的金币价值（Gold Value）缩放（与我们其他经验系统类似）。
  • 若玩家积累足够经验，将解锁一个音乐宝典升级点（Upgrade Point）。
  • 每个角色最多可解锁 20 个音乐宝典升级点。
  • 玩家永远不会丢失音乐宝典经验（若丢失宝典，只需再获得一本，经验与已解锁点数将与原先一致）。

Bard Codex 菜单 Bard Codex Menu

  • 双击背包中的音乐宝典，可打开属于该玩家的音乐宝典菜单。
  • 共有 8 种不同的音乐宝典升级可供玩家激活为 Tier 1、Tier 2 或 Tier 3 版本（层级由升级旁的鲁特琴（Lute）数量表示）。
  • 每个 Tier 等级的升级消耗不同数量的升级点来激活。
  • 玩家可点击每个升级条目旁的「信息 Info」按钮查看其效果描述。
  • 玩家可点击「Spend X Pts to Upgrade Tier」按钮提升该升级的层级。
  • 玩家可双击「Reset Spent Points」按钮，每 5 分钟重置一次所有选择。

Bard Codex 升级 Bard Codex Upgrades

  • 玩家必须拥有 80 或以上的技能（音乐家、安抚、挑衅、不和谐）中至少两项，方可使用任何音乐宝典升级。
  • 以下为可用的音乐宝典升级列表：

Bard 设置 Bard Settings

  • 玩家可点击音乐宝典上的「Bard Settings」按钮，打开 Bard 设置菜单。
  • 在 Bard 设置菜单中，玩家可切换其吟游歌曲是否作用于同一队伍（Party）、公会（Guild）或盟友（Allies）的成员（注意：玩家须重新激活吟游歌曲，才能使其作用于此前未选择的新玩家群体）。
  • 玩家还可切换哪些玩家能够利用自己施加到生物上的「生物效果」（如不和谐的增益 / 减益）。
