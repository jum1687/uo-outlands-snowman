ClassicUO 客户端命令 ClassicUO Commands

以下命令由 ClassicUO 客户端提供（与服务器无关），用于查看物品属性、切换客户端选项等。

ClassicUO 客户端 ClassicUO Client
命令 Command说明 Description
-info对准物品可查看其属性
-datetime显示服务器日期与时间
-hue对准物品可查看其色号（以系统消息显示）
-debug在游戏世界的图形周围绘制边框
-toggle <选项名>通过命令切换 Classic UO 客户端的各项选项
-ignore对准某玩家，将其加入客户端忽略名单
-savenecrobar保存死灵能力栏（Gump）的当前位置
-savechivbar保存骑士能力栏（Gump）的当前位置
-savecodexbar（已失效）保存宝典能力栏（Gump）的当前位置（可能已失效）
