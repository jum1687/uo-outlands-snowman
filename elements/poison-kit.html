毒药工具包 Poison Kit

系统总览 Summary

  • 玩家可用 炼金（Alchemy）技能制作毒药工具包（Poison Kit）。
  • 它是祝福（Blessed）物品，可让玩家自定义自身中毒效果作用于生物时的处理方式。
  • 这些加成永远不会影响玩家（即只对 PvM 生效，不影响 PvP）。

毒药工具包档案 Poison Kit Profile

  • 若玩家背包中携有毒药工具包，且拥有 下毒（Poisoning）≥ 80，并同时具备 味觉鉴定（Taste Identification）≥ 80 或 炼金（Alchemy）≥ 80，即可为该角色累积毒药工具包经验。
  • 当携带毒药工具包且满足技能要求的玩家，对生物施加剧毒（Greater Poison）或更高的中毒时，将依据其造成的总毒素伤害获得毒药工具包经验，该经验还会按生物的金币价值进行缩放（与其他经验系统类似）。
  • 累积足够经验后，将解锁 1 点毒药工具包升级点。
  • 每名角色最多可解锁 20 点毒药工具包升级点。
  • 毒药工具包经验永远不会丢失——即便工具包遗失，重新获得一个后，经验值与已解锁点数都与之前完全一致。

毒药工具包菜单 Poison Kit Menu

  • 双击背包中的毒药工具包，即可打开该角色的毒药工具包菜单。
  • 共有 8 种毒药工具包升级可选，每种都可激活为 1 阶位 / 2 阶位 / 3 阶位版本（阶位高低由升级项旁的毒药瓶数量表示）。
  • 每个升级项的各个阶位，激活所需的升级点数各不相同。
  • 点击各升级项旁的 Info 按钮，可查看该升级的效果说明。
  • 点击「Spend X Pts to Upgrade Tier」按钮，可提升该升级项的阶位。
  • 若玩家在世界中没有任何活跃的中毒效果，可双击「Reset Spent Points」按钮，重置全部已分配的点数。

毒药工具包升级 Poison Kit Upgrades

  • 玩家必须拥有 下毒（Poisoning）≥ 80 才能使用任何毒药升级。
  • 毒药升级永远不会作用于其他玩家（仅作用于生物）。
  • 毒药升级的效果仅对剧毒（Greater Poison）及以上的中毒生效。
