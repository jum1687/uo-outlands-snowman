概要 Overview

虹彩核心（Chromatic Core）是元素精通（Aspect Mastery）体系中的特殊转换材料，不同于其他 25 种拥有独立武器 / 护甲 / 魔法书特效的常规元素。它本身没有专属的武器、护甲或魔法书加成，而是作为一种「万能核心」，可通过炼金术（Alchemy）转换为任意特定元素的元素核心（Aspect Core）或元素蒸馏物（Aspect Distillation）。此外，元素护符（Aspect Phylacteries）也可反过来提炼为虹彩核心 / 虹彩蒸馏物，作为低需求元素材料的回收途径。

说明：官方 Wiki 中「Chromatic Core」词条会跳转到「炼金术（Alchemy）」页面的「元素转换（Aspect Conversions）」章节。本页内容忠实译自该处与虹彩核心相关的全部原文。

虹彩转换 Chromatic Conversions

玩家可通过炼金术，在「Chromatic → Core（虹彩 → 核心）」分类下，将虹彩核心以 1 比 1 的比例转换为特定的元素核心；在「Chromatic → Distill（虹彩 → 蒸馏物）」分类下，将虹彩蒸馏物以 1 比 1 的比例转换为特定的元素蒸馏物。

虹彩核心 → 指定元素核心：1 比 1（1-to-1） 虹彩蒸馏物 → 指定元素蒸馏物：1 比 1（1-to-1） 所需技能：炼金术（Alchemy）100 级

护符转换 Phylactery Conversions

玩家还可通过炼金术，在「Phylactery → Core（护符 → 核心）」分类下，将元素护符转换为对应元素的核心或虹彩核心；在「Phylactery → Distill（护符 → 蒸馏物）」分类下，转换为对应元素的蒸馏物或虹彩蒸馏物。

  • 护符转换为对应元素的核心 / 蒸馏物：4 比 1（4-to-1）。
  • 护符转换为虹彩核心 / 虹彩蒸馏物：8 比 1（8-to-1）。
护符 → 对应元素核心 / 蒸馏物：4 比 1 护符 → 虹彩核心 / 虹彩蒸馏物：8 比 1 所需技能：炼金术（Alchemy）100 级
