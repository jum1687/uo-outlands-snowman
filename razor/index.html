使用须知 Before You Run

  • 取物品 ID：游戏内输入 -info 回车，再点向目标物，读 Object Information 里的 Serial:（形如 0x754DEB39），不要读下面十进制的 SerialDec。
  • 脚本不必开满速：每一步都靠等待时间对齐服务器，把 wait 调小反而会漏动作。
  • 城区部分区域禁发言：靠 say "[…" 发的方括号指令在刷广告的挂机区会被吞，宏照跑但人不动。此类区域改用界面按钮路径。
  • 先看刹车再跑：好的脚本会在关键节点自检（比如「能否打开锁在原地的书」＝人是否真的到位），不对就停下报警，而不是硬跑下去。

本页为粉丝自制工具（非官方），脚本基于社区 Razor 语法实测整理；如遇失效，多半是游戏机制变动，欢迎回报。
